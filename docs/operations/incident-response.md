# Incident response

Pause mutating automation, preserve structured output, revoke exposed credentials, and inventory affected resources. Use a narrowly scoped remediation script against verified IDs, preview it, obtain approval, then verify the result.

For a hung process, capture logs and transport configuration, terminate it safely, and confirm gateway, socket, MCP listener, timers, and child processes are released. For Discord incidents, stop retries, check audit logs, and use compensating changes rather than assuming rollback is transactional.
