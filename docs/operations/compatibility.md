# Compatibility

The package requires Node.js 26+ and tracks Discord.js through the adapter. CLI flags, JSON shapes, exit codes, error codes, `.ds` grammar, environment names, daemon transports, safety defaults, and package bin paths are compatibility-sensitive.

MCP targets stable initialization, tools, resources, prompts, Streamable HTTP, SSE, and stdio capabilities exposed by the installed SDKs. Pin and test the server, client, and SDK together; document migrations and keep examples aligned.
