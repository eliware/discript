# Rollback

Package rollback means installing a previously published version. Discord-state rollback means a compensating script with recorded IDs; Discord provides no universal transaction. Preview cleanup and require explicit approval for deletion.

Stop the daemon or pause automation, preserve logs and configuration, install the known-good package, restart one instance, and run a read-only health check. For partial provisioning, restore only resources created by the failed run and verify permissions, parents, ordering, and messages.
