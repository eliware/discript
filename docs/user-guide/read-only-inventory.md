# Read-only inventory

Start automation with a read-only inventory: list guilds, inspect channels and roles, and save normalized IDs and names as variables. Prefer JSON output for agents and stable IDs for all later mutations.

Inventory is safe to run against production, but permissions and visibility still determine what Discord returns. See [resource aliases](../cli/resource-aliases.md), [Discord resources](../discord/README.md), and the [test-guild workflow](../developers/test-guild.md).
