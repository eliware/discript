# Script workflows

Scripts compose Discord calls with variables, functions, loops, conditionals, environment values, and event handlers. Store a result, inspect it, and pass selected fields into the next operation rather than hardcoding IDs.

Use stdin for ephemeral agent-generated scripts and files for repeatable deployments. Keep one-shot scripts finite; listeners, timers, and loops intentionally keep the runtime alive. Browse the [runnable examples](../../examples/README.md) and [language reference](../language/reference.md).
