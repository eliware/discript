# Voice channels

Voice channels use the same channel lifecycle as text channels: they can be discovered, created, updated, moved between categories, reordered, uncategorized, and deleted when supported permissions are present. Text-only fields such as a topic do not apply.

Provisioning should set the channel type explicitly and can apply parent and permission overwrites in the same way as other channels. Treat deletion and broad permission changes as destructive; preview and approve them.

See [channel operations](channels.md), [permissions](permissions-and-overwrites.md), and the [examples index](../../examples/README.md).
